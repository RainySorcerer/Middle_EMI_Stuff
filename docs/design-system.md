# PaisaPilot Design System

A clean, trustworthy, India-first personal finance product. Calm, data-dense but never overwhelming. Mobile-first (most users will be on phone), with a desktop dashboard that feels like a financial cockpit.

> This is the implementation source of truth for tokens, tone and screen composition. The PDF-derived requirements live in [`prd.md`](./prd.md).

## Brand identity

- **Logo:** stylized ₹ with a small upward arrow / compass needle (guidance + money). Wordmark in a geometric sans. Dark teal + gold.
- **Colors:**
  - Primary: Deep Teal `#0F766E`
  - Accent / India: Warm Gold `#D97706`
  - Success: `#059669`
  - Warning: `#D97706`
  - Danger: `#DC2626`
  - Background: `#F8FAFC` / white
  - Cards: white with very subtle shadow
  - Text: `#0F172A` (headings), `#475569` (body)
- **Typography:** Inter (or Geist) for UI. Numbers in a slightly condensed tabular font so ₹ amounts align perfectly.
- **Tone:** Clear, non-judgmental, slightly encouraging. "You're at 34% utilization — still okay, but let's bring it under 30%." Never scolding.
- **Icons:** Lucide or Phosphor, 1.5px stroke, consistent.

## Core principles

- Numbers first, then explanation.
- Every recommendation has a quantified ₹ impact.
- One primary action per screen.
- Heavy use of progress rings, gauges and small sparklines.
- Trust signals everywhere: "Your data never leaves India", "No bank login required", "Delete everything in one click".

## Key screens

### 1. Onboarding / financial profile intake (under 5 minutes)

Multi-step wizard with a progress bar at the top.

1. Basics (income, city, tax regime)
2. Credit cards (add 1–4 cards: last 4 digits, limit, current outstanding, due date, rewards type)
3. SIPs & investments
4. Loans / EMIs
5. Monthly expenses (fixed + variable, or "I'll upload CSV later")
6. Review + generate first report

Smart defaults, rupee formatting, "Skip for now" on most fields. Big "Get my first report" button at the end.

### 2. Main dashboard

Layout: mobile stacks, desktop 12-column.

**Top bar:** Logo | Month selector | Notifications | Profile

**Hero row (4 compact metric cards):**

- Net Worth (with 3-month sparkline)
- Overall Credit Utilization (big ring + "34% • Watch")
- Monthly Cash Flow (green/red)
- Next EMI due (countdown)

**Main content:**

- Left / top: **Credit Utilization** — one ring per card + overall. Color bands (green <30%, amber 30–50%, red >50%). Tiny "Pay before 12th" reminder.
- Center: **Recommended Actions** (the money maker). 3–5 cards, ranked. Each shows title, estimated monthly/annual impact in ₹, confidence + one-line why, and `[Done] [Dismiss] [Tell me more]`.
- Right: **SIP Allocation** donut (Equity / Debt / Hybrid / Emergency) + flags ("Emergency fund is only 3.2 months").
- Bottom: **EMI Timeline** (horizontal bars showing remaining tenure + total interest left) + **Net Worth trend** (6–12 month line).

### 3. Monthly AI report

Full-width, magazine-like but scannable.

- Header: "Your June 2025 Report" + overall score / "You saved ₹1,840 this month"
- Short narrative paragraph generated by Claude (2–3 sentences)
- Ranked actions (same as dashboard but with more explanation)
- Before/after comparison vs last month
- "What changed" section
- Big disclaimer at bottom: "Informational only. Not financial advice."

### 4. Supporting screens

- **Card Matcher (P1):** spend categories vs cards, ranked by net annual value.
- **EMI Simulator:** "What if I take this new loan?" slider.
- **Tax Planner:** 80C / 80D remaining headroom + old vs new regime toggle.
- **History:** monthly snapshots, simple timeline.
- **Privacy / Delete:** extremely prominent "Delete all my data" button.

## Component patterns

- **Gauges:** circular progress with colored bands, not just 0–100.
- **Action cards:** white, left accent bar in teal/gold, large ₹ impact number.
- **Empty states:** friendly illustrations + "Add your first card in 30 seconds".
- **Micro-interactions:** subtle confetti or check animation when a user marks an action done. Numbers animate on load.
- **Mobile:** bottom tab bar — Dashboard | Report | Cards & SIPs | Profile.

## Technical notes

- React / Next.js + Recharts (or Tremor for faster finance charts).
- Tailwind + custom tokens matching the palette above.
- All calculations in backend (Python/FastAPI) — frontend only displays.
- Dark mode later (many Indian users prefer it at night).

This design stays strictly within the PRD: no transaction execution, no stock picking, education + analysis only, India-specific (₹, 80C, Account Aggregator later).
